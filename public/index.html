Últimas alterações

    ICMS-ST nas compras de outros estados

    Itens de notas de fora do ES, sem ST retido pelo fornecedor, que estão na tabela de ST do ES. Base ST = (mercadoria + frete + seguro + IPI + outras − desconto) × (1 + MVA), ou PMPF × quantidade; ICMS-ST = Base ST × alíquota interna − ICMS próprio.

    Adicionar empresa

    Selecione o certificado A1 Arquivo .pfx ou .p12. Clique ou arraste aqui.
    Não tenho o arquivo, o certificado está instalado no Windows
    1. Aperte Win + R, digite certmgr.msc e confirme.
    2. Abra Pessoal → Certificados, clique com o botão direito no certificado da empresa e escolha Todas as tarefas → Exportar.
    3. Marque Sim, exportar a chave privada, escolha o formato .PFX, defina uma senha e salve.
    4. Envie esse arquivo aqui com a senha que você definiu.

    Se a opção de exportar a chave privada estiver desabilitada, o certificado foi instalado como não exportável. Nesse caso, use o arquivo original entregue pela certificadora.

    Campos opcionais

    O certificado e a senha são criptografados no servidor antes de irem para o banco. A senha não fica visível para ninguém depois do envio.
